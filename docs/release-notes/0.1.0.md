# Stream Privacy Guard 0.1.0 (draft release notes)

**Draft. Not published.** No GitHub release, tag or download exists for this
version. A human decides whether and when to publish, after the live check and
leak test in [live-check.md](../live-check.md). Update this file as the
tickets below land; it describes the tree it is committed in.

## What it is

An OBS Studio filter that blurs faces, watch-listed text (a real name, an
address) and structured personal data (emails, phone and card numbers, IP and
street addresses, API and stream keys) on a source before it airs. It is a
safety net, not a guarantee: anything it misses has already aired.

## In this version

- **Privacy Guard filter** for OBS Studio 32 (built against libobs 32.1.2):
  watch-list, detection categories, sensitivity, lookahead, mask hold,
  fallback and a debug overlay ([settings.md](../settings.md)).
- **Lookahead, readback and GPU blur** in the plugin: frames are held for the
  lookahead, masks reach back to every buffered frame, and a frame that was
  not scanned in time airs covered whole by the fallback
  ([plugin-render.md](../plugin-render.md)).
- **Watch-list secrecy:** entries live in a user-only file outside the scene
  collection, never in logs, held in wiped memory that is excluded from crash
  dumps on Linux and from Windows Error Reporting dumps.
- **Detection core** (`spg-core`): YuNet faces, PP-OCR text detection and
  recognition through ONNX Runtime 1.30.0, the PII and watch-list policy, the
  tracker and the fail-closed scheduler, tested headless on all three OSes.
- **Packages** for macOS (Apple Silicon), Windows x64 and Linux x86_64, built
  by `scripts/package.sh` with install notes and third-party licenses. Models
  are fetched separately by `scripts/fetch_models.py` (pinned, SHA-256
  verified).

## Not in this version

- **The plugin does not load the detection models yet** (SPG-14b,
  [#61](https://github.com/neanicc/stream-privacy-guard/pull/61)): every frame
  airs covered whole after the lookahead. Until that lands this version
  protects nothing beyond a whole-source blur.
- **No measured accuracy.** The end-to-end synthetic eval (SPG-11) has not
  landed; no recall or over-blur number exists for the thresholds in
  `eval/thresholds.toml`.
- **No live OBS verification** and no human leak test.
- **No GPU inference on Windows or Linux** (CPU only); no Intel macOS build;
  no Flatpak build.
- **No signed or notarized packages**; macOS bundles are ad-hoc signed only.

## Install and upgrade

See the [README](../../README.md#install) or `INSTALL.txt` in each package.
There is no earlier version to upgrade from. Remember to set the audio Sync
Offset to the lookahead.

## Known issues

All of the README's [limitations](../../README.md#limitations) apply,
notably: small faces (under about 30 px at 1080p) and small text (cap height
under about 10 px) may be missed; upside-down text is not read; about 240 MB
of video memory at 1080p60 with the default 500 ms lookahead; watch-list
files of deleted filters stay on disk until removed by hand.
