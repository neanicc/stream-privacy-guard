Stream Privacy Guard (obs-spg) for OBS Studio on Linux x86_64
=============================================================

An OBS filter that blurs faces, watch-listed text and personal data on a
source before it airs. It is a safety net, not a guarantee: anything it
misses has already aired. Read "Limitations" in the project README before
relying on it: https://github.com/neanicc/stream-privacy-guard

Requirements
  - x86_64 Linux with glibc 2.39 or later. Built on Ubuntu 24.04; other
    distributions are untested.
  - OBS Studio 32.1 or a later 32.x release, installed natively (built
    against the official OBS 32.1.2 Ubuntu 24.04 package). The Flatpak OBS
    is not supported by this package.
  - Python 3 (3.12 tested) and curl, once, to fetch the detection models.
  - Detection runs on the CPU.

Install
  1. Quit OBS.
  2. Copy the obs-spg folder into
       ~/.config/obs-studio/plugins/
     (create the folder if it does not exist), so that the module is at
       ~/.config/obs-studio/plugins/obs-spg/bin/64bit/obs-spg.so
  3. Fetch the models (next section).
  4. Start OBS. Right-click a source > Filters > Effect Filters > + >
     Privacy Guard.

  This build is not signed. Keep the files in obs-spg/bin/64bit together
  and do not replace any of them with another copy.

Models
  The package carries no model weights. From this folder, run once:
       python3 scripts/fetch_models.py
  It downloads YuNet and PP-OCR from the pinned URLs in
  models/manifest.json, checks each file's size and SHA-256, and installs
  them in ~/.cache/spg/models (or $SPG_CACHE_DIR/models). The plugin checks
  them again before loading and downloads nothing. Without the models the
  filter cannot detect anything and fails closed: it blurs the whole source.
  Restart OBS after fetching.

Audio
  The filter delays the video by its Lookahead (500 ms by default). Set the
  same Sync Offset in Edit > Advanced Audio Properties on every audio source
  that belongs with the video.

Uninstall
  Delete ~/.config/obs-studio/plugins/obs-spg. Watch-list files stay in
  ~/.config/obs-studio/plugin_config/obs-spg/ until you delete them; the
  models stay in ~/.cache/spg/models.
