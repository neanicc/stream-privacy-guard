Stream Privacy Guard (obs-spg) for OBS Studio on macOS, Apple Silicon
=====================================================================

An OBS filter that blurs faces, watch-listed text and personal data on a
source before it airs. It is a safety net, not a guarantee: anything it
misses has already aired. Read "Limitations" in the project README before
relying on it: https://github.com/neanicc/stream-privacy-guard

Requirements
  - macOS 14 or later on Apple Silicon (arm64). No Intel build.
  - OBS Studio 32.1 or a later 32.x release. Built against libobs 32.1.2;
    other OBS versions are untested.
  - Python 3 (3.12 tested) and curl, once, to fetch the detection models.

Install
  1. Quit OBS.
  2. Copy obs-spg.plugin into
       ~/Library/Application Support/obs-studio/plugins/
     (create the plugins folder if it does not exist).
  3. This build has only an ad-hoc signature: it is not signed with a
     developer certificate or notarized. If the archive was downloaded with
     a browser, macOS quarantines it; remove the mark so OBS can load it:
       xattr -dr com.apple.quarantine ~/Library/Application\ Support/obs-studio/plugins/obs-spg.plugin
  4. Fetch the models (next section).
  5. Start OBS. Right-click a source > Filters > Effect Filters > + >
     Privacy Guard.

Models
  The package carries no model weights. From this folder, run once:
       python3 scripts/fetch_models.py
  It downloads YuNet and PP-OCR from the pinned URLs in models/manifest.json,
  checks each file's size and SHA-256, and installs them in
  ~/.cache/spg/models (or $SPG_CACHE_DIR/models). Nothing in the plugin
  downloads anything. Without the models the filter cannot detect anything
  and fails closed: it blurs the whole source.

Audio
  The filter delays the video by its Lookahead (500 ms by default). Set the
  same Sync Offset in Edit > Advanced Audio Properties on every audio source
  that belongs with the video.

Uninstall
  Delete ~/Library/Application Support/obs-studio/plugins/obs-spg.plugin.
  Watch-list files stay in
  ~/Library/Application Support/obs-studio/plugin_config/obs-spg/ until you
  delete them; the models stay in ~/.cache/spg/models.
